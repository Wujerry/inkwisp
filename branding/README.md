# InkWisp brand assets

- `inkwisp-icon-master.png` is the full-resolution generated water-ink master.
- `play-store-icon.png` is the 512×512 Google Play listing asset.
- `app/src/main/res/drawable-nodpi/ic_launcher_inkwash.png` is the 1024×1024 Android adaptive-icon foreground and in-app brand mark.
- `inkwisp-icon.svg` and `app/src/main/res/drawable/ic_launcher_foreground.xml` remain the deterministic monochrome/themed-icon fallback.

The raster icon was generated with the built-in image generation tool using this direction: a single flowing black sumi-e gesture, quiet warm xuan paper, one muted vermilion point, strong small-size silhouette, generous adaptive-icon safe area, and no text, border, mockup, shadow, or decorative landscape motifs.

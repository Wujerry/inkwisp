# InkWisp privacy policy on GitHub Pages

The repository publishes the bilingual policy from `docs/privacy/index.html`.

- Public developer identity: **JerryWu (GitHub: Wujerry)**
- Privacy inquiry mechanism: the repository's dedicated privacy issue form
- Expected policy URL: `https://wujerry.github.io/inkwisp/privacy/`
- Developer website: `https://wujerry.github.io/inkwisp/`

GitHub Pages is suitable for the Google Play privacy-policy URL because the page is public, reachable without signing in, served over HTTPS, and delivered as HTML rather than PDF.

## GitHub Pages configuration

1. Open **Repository → Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/docs`, then save.
4. Open `https://wujerry.github.io/inkwisp/privacy/` in a private browser window.
5. Use that exact HTTPS URL in Play Console's privacy-policy field.

If the public developer name used in Play Console changes, update it in both `docs/privacy/index.html` and `docs/privacy-policy.md` so the store listing and policy remain consistent.

Play Console still requires a verified account contact email and phone number. Those private verification fields must be completed inside the user's Play Console account; they are separate from the public privacy inquiry mechanism on this site.

INKWISP / 续墨

Privacy Policy

Effective date: July 29, 2026

InkWisp (续墨) is an open-source, local-first Markdown editor published by JerryWu (GitHub: Wujerry). This policy explains how the official Android application accesses and handles data.

Local files

InkWisp accesses only files and folders selected through Android's system file picker. Documents, local search indexes, recovery copies, revision history, application settings, and model credentials are stored on the user's device. InkWisp does not operate an account, synchronization, analytics, or document-storage server.

Users can remove workspace access through InkWisp or Android settings. Uninstalling InkWisp deletes app-private settings, credentials, indexes, recovery copies, and revisions; it does not delete user-owned workspace documents or attachments.

Optional AI model services

AI features stay disabled until a user configures a model connection and accepts the in-app data-transfer disclosure. An AI edit sends the complete active document and up to four locally retrieved or explicitly referenced workspace passages directly from the device to the endpoint configured by the user so the model can preserve context and voice. Inline prediction sends only a limited excerpt around the cursor. A connection test sends fixed test text and no document content.

The publisher does not receive these requests or responses. The configured model provider processes data under its own privacy, retention, and security terms. HTTPS is recommended; user-configured HTTP endpoints, intended for local services, are not encrypted in transit.

Credentials and security

Model credentials are encrypted with a device-bound key held by Android Keystore. They are not displayed after storage and are never included in configuration exports, diagnostics, or workspace files.

Diagnostics, advertising, and sale

InkWisp does not collect behavioral analytics and the current release contains no remote crash-reporting or advertising SDK. InkWisp does not sell user data. Any future release that adds advertising or diagnostics will update this policy and the Google Play Data safety declaration before publication.

Retention and deletion

App-private data remains on the device until the user deletes it or uninstalls InkWisp. User-owned workspace files remain under the user's control. Data sent to a user-configured model endpoint is retained or deleted according to that provider's terms.

Children

InkWisp is a general-purpose writing tool and is not directed to children. It does not provide social, chat, or account features.

Changes

Material changes will be published in the application and at this public URL before they take effect.

续墨隐私政策

生效日期：2026 年 7 月 29 日

续墨（InkWisp）是由 JerryWu（GitHub：Wujerry）发布的开源、本地优先 Markdown 编辑器。本政策说明官方 Android 应用如何访问和处理数据。

本地文件

续墨仅访问用户通过 Android 系统文件选择器主动选择的文件和文件夹。文档、本地搜索索引、恢复副本、版本历史、应用设置和模型凭据均保存在用户设备上。续墨不运营账号、同步、行为分析或文档存储服务器。

可选 AI 模型服务

只有在用户配置模型连接并确认应用内数据传输说明后，AI 功能才会启用。AI 编辑会把当前完整文档及最多四段本地检索或明确引用的工作区内容从设备直接发送到用户配置的端点，以保留上下文和写作语气；行内预测只发送光标附近的有限片段。发布者不会接收这些请求或回复，服务商的数据处理、保留与安全条款适用。

凭据与安全

模型凭据使用 Android Keystore 中的设备绑定密钥加密；保存后不再显示，也不会进入配置导出、诊断信息或工作区文件。

保留与删除

应用私有数据会保留在设备上，直到用户删除或卸载续墨。用户自己的工作区文件始终由用户控制。发送到用户配置模型端点的数据，按对应服务商条款保留或删除。

诊断、广告与数据出售

当前版本不收集行为分析数据，不包含远程崩溃报告或广告 SDK，也不出售用户数据。未来版本若加入广告或诊断，会在发布前同步更新本政策和 Google Play“数据安全”声明。

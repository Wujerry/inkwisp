# Local-first without accounts

InkWisp's first release stores user-owned Markdown documents on the Android device and requires no InkWisp account, proprietary cloud service, model proxy, or business backend. AI assistance uses Direct Model Requests from the device to user-configured services, while documents are never synchronized through InkWisp infrastructure; this keeps the release focused on editing and inline prediction, reduces privacy exposure, and avoids committing to backend and identity models.

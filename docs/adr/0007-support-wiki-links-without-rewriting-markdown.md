# Support Wiki Links without rewriting Markdown

InkWisp will recognize `[[document]]`, `[[document#heading]]`, and `![[document]]` inside Workspaces and derive navigation, missing-link, embedding, and backlink behavior from them. These extensions remain literal user-authored source and will not be normalized into a proprietary document format or automatically converted to standard Markdown links. This adds knowledge-workspace behavior while preserving file portability and lossless source editing.

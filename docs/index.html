INKWISP / 续墨

Write without giving up your files.

InkWisp is an open-source, local-first Markdown editor for Android. Documents remain in folders you choose. AI features are optional and use only model services you configure.

续墨是一款开源、本地优先的 Android Markdown 编辑器。文档保存在你选择的文件夹中；AI 功能完全可选，只连接你主动配置的模型服务。
